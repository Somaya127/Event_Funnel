# دورة قاعدة النور - مركز كفرعان القرآني

## مشروع تسويقي متكامل لتسجيل الأطفال في دورة تأسيس القرآن

### نظرة عامة
هذا المشروع هو نظام تسويقي متكامل (Registration Funnel) لدورة "قاعدة النور" في مركز كفرعان القرآني، مصمم لتأسيس الأطفال (5-8 سنوات) على قراءة القرآن بطلاقة.

### هيكل المشروع

#### الصفحات الرئيسية
1. **index.html** - الصفحة الرئيسية وجذب الانتباه
2. **middleFirst.html** - صفحة التفاصيل والأسئلة الشائعة
3. **bottom.html** - صفحة القرار النهائي
4. **form.html** - نموذج التسجيل متعدد الخطوات
5. **confirmation.html** - صفحة تأكيد التسجيل
6. **postFunnel.html** - صفحة الاحتفاظ بالعملاء المحتملين

#### الملفات التقنية
- **style.css** - تصميم متجاوب وجذاب
- **script.js** - وظائف JavaScript وتحليلات
- **workflow.md** - وثائق سير العمل

### المميزات الرئيسية

#### 🎯 التسويق والمبيعات
- مسار تسويقي متكامل (Funnel)
- صفحات هبوط محسّنة للتحويل
- دعوات واضحة للعمل (CTA)
- نظام احتفاظ بالعملاء المحتملين

#### 📱 التصميم والتجربة
- تصميم عصري وجذاب
- متجاوب مع جميع الأجهزة
- تجربة مستخدم سلسة
- دعم كامل للغة العربية RTL

#### 📊 التحليلات والتتبع
- تتبع شامل لجميع التفاعلات
- تحليلات سلوك المستخدم
- قياس معدلات التحويل
- إدارة البيانات المحلية

#### 📋 النماذج والبيانات
- نموذج تسجيل متعدد الخطوات
- التحقق من صحة البيانات
- حفظ البيانات المحلي
- تتبع إكمال النموذج

### التقنيات المستخدمة

#### الواجهة الأمامية
- **HTML5** - بنية الصفحات الدلالية
- **CSS3** - تصميم متجاوب وحيوي
- **JavaScript** - تفاعل وتحليلات

#### الميزات التقنية
- **Responsive Design** - متوافق مع جميع الأجهزة
- **RTL Support** - دعم كامل للغة العربية
- **Local Storage** - حفظ البيانات محلياً
- **Analytics Integration** - تكامل مع خدمات التحليلات

### مسار المستخدم (User Journey)

1. **الاكتشاف** - الصفحة الرئيسية مع معلومات سريعة
2. **التعلم** - صفحة التفاصيل والأسئلة الشائعة
3. **القرار** - صفحة اتخاذ القرار النهائي
4. **التسجيل** - نموذج التسجيل متعدد الخطوات
5. **التأكيد** - صفحة تأكيد نجاح التسجيل
6. **المتابعة** - صفحة الاحتفاظ بالعملاء المحتملين

### التحليلات والمقاييس

#### أحداث التتبع
- مشاهدات الصفحات
- النقرات على الروابط
- تقدم النموذج
- إكمال التسجيل
- التفاعل مع واتساب
- معدلات التحويل

#### البيانات المحلية
- بيانات العملاء المحتملين
- تفاعلات المستخدم
- تقدم النموذج
- إحصائيات الصفحات

### التثبيت والتشغيل

1. **تحميل الملفات** - جميع الملفات في مجلد واحد
2. **فتح index.html** - بدء من الصفحة الرئيسية
3. **الاستضافة** - يمكن رفع الملفات على أي استضافة
4. **التحليلات** - إضافة كود Google Analytics (اختياري)

### المتطلبات التقنية

- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت (للواتساب والخرائط)
