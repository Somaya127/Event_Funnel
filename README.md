## 1️⃣ Project Description  
### *What You Are Building*

You will build an **Event Registration Website**.

The website guides a user through clear steps, from:

- Discovering an event  
- To registering successfully  

This journey is called a **funnel**:

> **One clear path → One clear goal → One clear result**

## 3️⃣ Project Requirements  
### *What Your Website Must Include*

### 🧭 Pages (Multi-Page Required)

Your funnel must include **at least 4 pages**:

#### 1. Main Page TOFU (`index.html`)
- Introduces the event  
- Has **one clear button** to continue  

#### 2. Details / Info Page (MOFU-1)
- Explains the event  
- Encourages the user to register  
  
#### 3. Details / Info Page (MOFU-2) - OPTIONAL
- FAQs(frequently asked questions)
- Trust signals (reviews, guarantees, credentials)


#### 3. Registration Page (BOFU)
- User enters information   

#### 4. Confirmation Page (Confiramtion)
- Shows a success message  
- Confirms registration  

#### 5. Retention Page (postFunnel) -OPTIONAL
- Additional resources
- Community or social links
- Follow-up messages or emails



📌 **Rule:**  
Each page has **one main purpose only**.

### نظرة عامة
هذا المشروع هو نظام تسويقي متكامل (Registration Funnel) لدورة "قاعدة النور" في مركز كفرعان القرآني، مصمم لتأسيس الأطفال (5-8 سنوات) على قراءة القرآن بطلاقة.
